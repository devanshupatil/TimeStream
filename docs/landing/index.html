Smart Intelligence

How smart is the YouTube filter?

Most tracking apps log everything. TimeStream uses a multi-signal scoring algorithm to decide if a YouTube video is actually educational before logging it.

+4 pts📌 Strong learning keyword in title ("tutorial", "how to", "explained")
+1.5🏷️ Tech keyword in title ("React", "Docker", "Python"...)
+4 pts🎓 Known educational channel (Fireship, FreeCodeCamp, NeetCode...)
+0.5📝 Educational cues in description ("source code", "follow along"...)
+0.5#️⃣ Tech hashtags found in description

Score ≥ 3 → ✅ Logged as "Learning"
Score < 3 → ❌ Silently ignored

"Top 10 Minecraft Moments" — ignored.
"Building a REST API with Node.js — Full Tutorial" — logged ✅

Architecture

How it works under the hood

A clean, local-first data pipeline engineered for reliability and privacy.

┌─────────────────────────────────────────────────────────────┐
│                     YOUR BROWSER                                   │
│  Chrome / Firefox Extension silently watches your tabs       │
│  ▸ Detects GitHub, YouTube, Reddit, AI tools                 │
│  ▸ Applies smart filters (3-min rule + content scoring)     │
└──────────────────────────┬──────────────────────────────────┘
                          │ POST localhost:3000/api/activity
                           ▼
┌─────────────────────────────────────────────────────────────┐
│                 TIMESTREAM DESKTOP APP                       │
│  Electron main process receives and deduplicates events    │
│  ▸ Persists to local JSON (activities.json)                  │
│  ▸ Watches OpenCode + Claude CLI session files               │
│  ▸ Sends live updates to the renderer via IPC                │
└──────────────────────────┬──────────────────────────────────┘
                           ▼
┌─────────────────────────────────────────────────────────────┐
│                      YOUR DASHBOARD                          │
│  Beautiful UI: Timeline · Analytics · Search · Learnings    │
└─────────────────────────────────────────────────────────────┘
1

Browser Extension Logs Your Activity

The custom Chrome (Manifest V3) and Firefox extension silently monitors your tabs. It applies a smart 3-minute rule and content scoring algorithm before logging anything — noise is filtered out automatically.

chrome-extension/ · firefox-extension/
2

Data POSTs to Your Local Node.js Server

The extension securely POSTs activity data to localhost:3000 — a lightweight HTTP server running inside Electron. Only your machine can reach it. Full CORS protection applied.

POST localhost:3000/api/activity
3

Async Write Queue Safely Persists Data

An async write-queue deduplicates and safely writes all data to a local JSON file, preventing corruption under heavy concurrent I/O load. Activities are capped at 1,000 entries with smart deduplication.

~/.config/TimeStream/activities.json
4

File Watcher Monitors AI CLI Sessions

A Node.js fs.watch() observer monitors your OpenCode and Claude CLI session directories in real-time, parsing raw JSON logs into structured session cards automatically.

~/.opencode/sessions/ · ~/.claude/projects/
5

Beautiful Dashboard Renders Everything

All data is visualized across the Dashboard, Timeline, Learnings, Analytics, and Search pages — built with Vanilla JS and dynamic CSS variable theming via Electron IPC.

Electron IPC · renderer/index.html

Setup Guide

Get started in 5 minutes

TimeStream runs on Linux (Ubuntu 20.04+ recommended) and requires Node.js v18+ and npm v8+.

Step 1 — Prerequisites

Make sure you have Node.js v18+, npm v8+, and build tools installed.

sudo apt install build-essential

Step 2 — Clone & Install

git clone https://github.com/[your-repo]/TimeStream.git
cd TimeStream
npm install && npx @electron/rebuild

Step 3 — Run the App

npm run dev

Step 4 — Install the Browser Extension

Chrome: Go to chrome://extensions → Enable Developer Mode → Load Unpacked → select chrome-extension/


Firefox: Go to about:debugging → This Firefox → Load Temporary Add-on → select firefox-extension/manifest.json

Step 5 — Browse Normally

TimeStream is now active. Open GitHub, watch a tutorial, chat with AI — your timeline will populate automatically within minutes.
